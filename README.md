# MyHome

> 不想再做没有灵魂的 CRUD，用真实需求驱动技术成长，拥抱 AI+。Scratching my own itch.

一个完全本地化部署的智能家居平台。从语音对话到设备控制，数据不出家门，隐私自己掌控。
