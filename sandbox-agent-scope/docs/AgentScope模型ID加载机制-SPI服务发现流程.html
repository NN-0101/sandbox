🔍 AgentScope 模型 ID 加载机制

SPI 服务发现 · 从 model("prov:model-name") 到实际 API 调用的完整流程

📌 术语：通过模型 ID 加载模型
在 AgentScope 中，通过 .model("提供商:模型名称") 这种 字符串 ID 方式来加载模型， 底层依赖 Java SPI（Service Provider Interface） 机制自动发现并匹配对应的 ModelProvider 实现。

一、调用入口

// QuickStartController.java HarnessAgent agent = HarnessAgent.builder() .name("quickStart") .model("deepseek:deepseek-v4-flash") // ← 通过 ID 加载模型 .build();

HarnessAgent.Builder.model(String modelId) 最终会调用 ModelRegistry.resolve(modelId)。

二、核心源码：ModelRegistry.resolve()

类路径： io.agentscope.core.model.ModelRegistry

/** * 通过模型 ID 解析并创建 Model 实例 * 调用方式：ModelRegistry.resolve("deepseek:deepseek-v4-flash") */ public static Model resolve(String modelId, ModelCreationContext context) { Objects.requireNonNull(modelId, "modelId"); String trimmed = modelId.trim(); // 步骤 1：查命名注册（手动注册的模型） Model named = namedModels.get(trimmed); if (named != null) return named; // 步骤 2：查缓存 ModelCacheKey cacheKey = cacheKey(trimmed, context); if (cacheKey != null) { Model cached = resolvedCache.get(cacheKey); if (cached != null) return cached; } // 步骤 3：查用户注册的 Factory ProviderEntry entry = findMatchingUserEntry(trimmed); // 步骤 4：【核心】通过 Java SPI 加载 ModelProvider 并匹配 ModelProvider provider = entry == null ? findServiceProvider(trimmed, context) // ← SPI 服务发现 : null; if (entry == null && provider == null) { throw new IllegalArgumentException("Cannot resolve model: " + trimmed); } // 步骤 5：创建 Model 实例并返回 return provider.create(trimmed, context); }

三、Java SPI 服务加载：loadServiceProviders()

/** * 通过 Java SPI 加载所有 ModelProvider 实现 * 扫描 classpath 中 META-INF/services/ 目录下的配置文件 */ private static List<ModelProvider> loadServiceProviders() { if (serviceProviders != null) return serviceProviders; synchronized (ModelRegistry.class) { if (serviceProviders == null) { List<ModelProvider> providers = new ArrayList<>(); // ★ Java SPI 核心 API：ServiceLoader.load() // 扫描所有 JAR 包中的 META-INF/services/ 目录 ServiceLoader<ModelProvider> loader = ServiceLoader.load(ModelProvider.class, classLoader); // 实例化所有配置文件中声明的 Provider 类 for (ModelProvider provider : loader) { providers.add(provider); } serviceProviders = List.copyOf(providers); } return serviceProviders; } }

四、Provider 匹配：findServiceProvider()

/** * 遍历所有已加载的 Provider，调用 supports() 判断是否匹配 */ private static ModelProvider findServiceProvider(String modelId, ModelCreationContext context) { for (ModelProvider provider : loadServiceProviders()) { // 调用每个 Provider 的 supports() 方法 if (provider.supports(modelId, context)) { return provider; // 返回第一个匹配的 Provider } } return null; }

五、DeepSeekModelProvider：匹配与创建

/** * DeepSeek 模型提供商实现 * 通过 SPI 自动发现，匹配 "deepseek:" 前缀的模型 ID */ public final class DeepSeekModelProvider implements ModelProvider { private static final String PREFIX = "deepseek:"; // ← ID 前缀 public static final String DEFAULT_BASE_URL = "https://api.deepseek.com"; // ============================================================ // 匹配方法：判断是否支持该 modelId // ============================================================ @Override public boolean supports(String modelId, ModelCreationContext context) { return modelId != null && modelId.startsWith(PREFIX); } // ============================================================ // 创建方法：构建 Model 实例 // ============================================================ @Override public Model create(String modelId, ModelCreationContext context) { String modelName = modelId.substring(PREFIX.length()); // → "deepseek-v4-flash" return OpenAIChatModel.builder() .apiKey(System.getenv("DEEPSEEK_API_KEY")) .baseUrl(DEFAULT_BASE_URL) .modelName(modelName) .build(); } @Override public String providerId() { return "deepseek"; // 与 ID 前缀保持一致 } }

七、完整流程图

.model("deepseek:deepseek-v4-flash") │ ▼ ModelRegistry.resolve() ← 模型 ID 解析入口 │ ├─ 1. 查 namedModels（手动注册）→ 无 ├─ 2. 查 resolvedCache（缓存）→ 无 ├─ 3. findMatchingUserEntry() → 无 │ ▼ findServiceProvider() ← 通过 SPI 查找 │ ├─ loadServiceProviders() │ │ │ ├─ ServiceLoader.load(ModelProvider.class) │ │ └─ 扫描所有 JAR 的 META-INF/services/ │ │ └─ 找到配置文件：io.agentscope.core.model.spi.ModelProvider │ │ └─ 内容包含 5 个 Provider 全限定名 │ │ │ └─ 遍历实例化所有 Provider: │ ├─ OpenAIModelProvider │ ├─ KimiModelProvider │ ├─ MiniMaxModelProvider │ ├─ GLMModelProvider │ └─ DeepSeekModelProvider ← 被加载 │ ▼ 遍历 Provider，调用 supports() 匹配 │ ├─ OpenAIModelProvider.supports() → false ├─ KimiModelProvider.supports() → false ├─ MiniMaxModelProvider.supports() → false ├─ GLMModelProvider.supports() → false └─ DeepSeekModelProvider.supports() → true ✅ │ ▼ DeepSeekModelProvider.create() │ ├─ 提取 modelName = "deepseek-v4-flash" ├─ 应用 DEFAULT_BASE_URL = "https://api.deepseek.com" ├─ 读取环境变量 DEEPSEEK_API_KEY └─ 返回 OpenAIChatModel 实例

八、扩展指南：接入公司自建模型

⚙️ 如果需要接入公司自己搭建的模型（非 OpenAI 兼容格式），需要自行实现 SPI。

步骤 1：实现 ModelProvider 接口

// 1. 创建自定义 Provider，放在 src/main/java/ 下 package com.yourcompany.agentscope.model; import io.agentscope.core.model.Model; import io.agentscope.core.model.ModelCreationContext; import io.agentscope.core.model.spi.ModelProvider; public final class MyCompanyModelProvider implements ModelProvider { private static final String PREFIX = "mycomp:"; @Override public boolean supports(String modelId, ModelCreationContext context) { return modelId != null && modelId.startsWith(PREFIX); } @Override public Model create(String modelId, ModelCreationContext context) { String modelName = modelId.substring(PREFIX.length()); // 返回自定义的 Model 实现 return MyCompanyChatModel.builder() .apiKey(context.getApiKey()) .baseUrl("https://api.your-company.com") .modelName(modelName) .build(); } @Override public String providerId() { return "mycomp"; } }

步骤 2：创建 SPI 配置文件

文件路径： src/main/resources/META-INF/services/io.agentscope.core.model.spi.ModelProvider

# 文件内容：写入你的 Provider 全限定类名 com.yourcompany.agentscope.model.MyCompanyModelProvider

步骤 3：使用自定义模型

// 通过模型 ID 加载公司自建模型 HarnessAgent agent = HarnessAgent.builder() .name("myAgent") .model("mycomp:my-model-name") // ← 使用自定义前缀 .build();
📌 关键点：
  • providerId() 必须与 ID 前缀保持一致（如 "mycomp"）
  • supports() 方法通过前缀匹配来决定是否处理该模型 ID
  • SPI 配置文件 必须放在 META-INF/services/ 目录下，文件名必须是接口全限定名
  • 打包成 JAR 后，META-INF/services/ 目录会被一同打包，ServiceLoader 自动发现
